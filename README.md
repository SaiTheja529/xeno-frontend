Xeno Assignment – Frontend

A modern, responsive React.js application built to support the multi-tenant Shopify Data Ingestion & Insights Service. This frontend serves as the user interface layer for managing Shopify store connections, triggering data sync operations, and exploring insights derived from ingested customer, product, and order data.

🚀 Tech Stack

React.js – UI framework

Vite / CRA – Build tooling (choose based on your setup)

Axios – API communication

TailwindCSS / Material UI (optional UI library)

React Router – Frontend routing

🧩 Features

User-friendly interface for onboarding Shopify stores

Input forms for adding shop credentials

API integration with backend services

Displays sync status, logs, and insights

Clean modular component structure

📦 Project Structure (sample)
src/
│── components/
│── pages/
│── services/
│── hooks/
│── utils/
└── App.jsx

🛠️ Development Setup

Install dependencies:

npm install


Start development server:

npm run dev

🔗 Backend Integration

This frontend communicates with the backend service via REST APIs defined in the xeno-backend repository.
