<h1>🌐 Xeno Assignment – Frontend</h1>

<p>
A modern, responsive <strong>React.js</strong> application built to support the multi-tenant 
<strong>Shopify Data Ingestion & Insights Service</strong>.  
This frontend acts as the user interface layer for connecting Shopify stores, triggering 
data sync operations, and visualizing insights generated from products, customers, and orders.
</p>

<h2>🚀 Tech Stack</h2>
<ul>
  <li><strong>React.js</strong> – UI framework</li>
  <li><strong>Vite / CRA</strong> – Build tooling (use whichever your setup supports)</li>
  <li><strong>Axios</strong> – API communication layer</li>
  <li><strong>TailwindCSS / Material UI</strong> – Optional UI styling</li>
  <li><strong>React Router</strong> – Frontend routing</li>
</ul>

<h2>🧩 Key Features</h2>
<ul>
  <li>Intuitive interface for onboarding Shopify stores</li>
  <li>Forms for collecting and validating Shopify credentials</li>
  <li>Seamless API integration with backend services</li>
  <li>Displays sync status, activity logs, and insights</li>
  <li>Clean, modular, maintainable folder structure</li>
</ul>

<h2>🛠️ Development Setup</h2>
<p><strong>Install dependencies:</strong></p>
<pre>npm install</pre>

<p><strong>Start development server:</strong></p>
<pre>npm run dev</pre>

<h2>🔗 Backend Integration</h2>
<p>
This frontend connects to the API endpoints provided by the 
<strong>xeno-backend</strong> service for handling Shopify sync operations and data retrieval.
</p>
